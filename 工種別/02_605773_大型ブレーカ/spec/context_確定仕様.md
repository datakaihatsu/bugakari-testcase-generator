## 2. SF変数の状態（JSON実測で確定）

### 2.1 SF値のハードコード

`KeisanItemCD:103` にて `Value: 1.0` が固定値として設定されている。

```json
{
  "KeisanItemCD": 103,
  "Mesho": " 省庁区分",
  "Value": 1.0,
  "VarName": "SF"
}
```

→ **このJSONは SF=1.0 で固定されており、国交省土木専用JSONである**

### 2.2 SF → 省庁行の自動選択

`SitsumonNo:1`（省庁区分）の `AutoSelectJoken`（MaxKigou=3 は「≦」）:

| RowID | 省庁名 | SF条件(≦) | 選択されるか |
|---|---|---|---|
| 4 | **国交省土木** | **1.0** | **✅ SF=1.0 はここ** |
| 5〜 | 他省庁 | >1.0 | ✗ |

→ **省庁区分はテストケースの列に含めない**（UIに表示されない内部変数）
