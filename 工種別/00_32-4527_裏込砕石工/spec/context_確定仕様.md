## 5. テスト設計方針

### 5.1 テスト区分の定義

- **差分**: 2025→2026で計算結果が変わるシナリオ。変更が正しく反映されているか確認する
- **回帰**: 2025→2026で計算結果が変わらないシナリオ。変更の影響を受けていないことを確認する

### 5.2 フェーズ1（治山林道×BH施工）は全件「差分」テスト

治山林道×BH施工の6件は全て差分テストである。理由：

- 施工歩掛値変更（S1A:0.7→0.8, S2A:1.3→1.6, S3A:3.3→3.6）がBH施工全件に影響
- 排ガス機械選択追加（SitsumonNo:38）がBH施工全件に影響
- 諸雑費率変更（0.7→0.4）は数量テスト対象外だが変更があるため差分扱い

「日当り施工量 × 施工費のみ」もLD=1.0（D値依存なし）だが、
歩掛値変更の影響を受けるため差分テストとなる。

**注意**: 真の回帰テスト（全変更の影響がゼロ）は「道林務×クレーン×日当り×施工費のみ」のみだが、
治山林道ではクレーン施工が動作しないため、フェーズ1内に回帰テストは存在しない。

## 7. 積算順ロジック（フェーズ2確定）

### 共通前処理：省庁区分の解決

```
SF = 2.1（KeisanItemCD:33 に固定値として設定）
SF2 = if(SF==2, if(pref==1, 53, 2), SF) = 2.1
SF2=2.1 → Sitsumon019 No:1 RowID=6（治山林道）を自動選択
→ SFK1a=1, SFK2=2, SFK3=1, SFK4=1 が設定される
SFK3=1 → ルートA（BH施工）に固定
```

### ルートA：バックホウ施工（SFK3=1）

```
A-1: 施工歩掛基礎値（SitsumonNo:3）
     2025: S1A=0.7, S2A=1.3, S3A=3.3, S5A=1
     2026: S1A=0.8, S2A=1.6, S3A=3.6, S5A=1

A-2: AT決定
     A=0  → AT=D（2025:38.0 / 2026:40.0）
     A=10 → AT=10
     A=100→ AT=100

A-3: LD = AT/D（A=0のとき LD=1.0 固定・D値依存なし）

A-4: 歩掛数値計算
     S1=S1A×LD / S2=S2A×LD / S3=S3A×LD
     S4=AT×1.2（2025）/ AT×1.3（2026）← sk=1のみ
     S5=S5A×LD

A-5: 排ガス機械選択（2026のみ）
     FG~01=66（排ガス対策型 2014年規制 ★デフォルト）
     FG~01=64（排ガス対策型 第3次基準値）
     ※どちらを選択してもS1〜S5の数量は変わらない

A-6: バックホウ運転費へ変数送信（数量テスト対象外）
```

### ルートB：クレーン施工（SFK3=2 / 道林務のみ）

```
※ 治山林道（SF=2.1）では SFK3=1 固定のため動作しない。
  道林務（SF2=54）専用パス。フェーズ2（自動テスト導入後）で実行。

B-1: 施工歩掛基礎値（SitsumonNo:4）※2025/2026共通
     つき固有: S1A=0.7, S2A=1.3, S3A=3.3, S5A=1
     つき固無: S1A=0.7, S2A=0,   S3A=3.3, S5A=1

B-2〜3: AT・LD計算（ルートAと同じ）
B-4: 歩掛数値計算（ルートAと同じ式）

```
