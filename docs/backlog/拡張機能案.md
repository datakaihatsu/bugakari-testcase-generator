# 拡張機能案
# 作成: 2026-05-26

---

## 発端

03_送気用設備運転費の修正方針.txt と step1.0_差分レポート.csv を照合した結果、
以下の知見が得られた。これをもとに将来追加したい機能をまとめる。

### 照合結果サマリ（03工種での実測）

| 観点 | 結果 |
|---|---|
| 修正方針の網羅率（完全合致） | 62.5%（5/8項目） |
| 修正方針の網羅率（部分・間接含む） | 87.5%（7/8項目） |
| 差分レポートの情報量 | 修正方針の約6〜7倍 |
| 差分レポートで検出できなかった修正方針の項目 | 丸め設定 / 規格名計上設定 |

## 拡張機能案

### 案A：修正方針との自動照合機能

**概要**  
修正方針.txt（または類似の仕様文書）と step1.0_差分レポート.csv を自動で突き合わせ、
合致度をレポートとして出力する。

**想定入力**
- 修正方針.txt（自然言語の箇条書き）
- step1.0_差分レポート.csv

**想定出力**
- 修正方針の各項目が差分レポートで確認できるか（✅ / ⚠️ / ✗）
- 合致度（%）
- 差分レポートにあって修正方針にない超過分の一覧

**難易度**  
修正方針が自然言語のため、キーワードマッチングかLLMによる意味照合が必要。

---

### 案B：差分レポートの「見かけ変更」と「実質変更」の自動分類

**概要**  
差分レポートの変更件数が多い要因の一つは、JSONの番号シフト（SitsumonNoの付け替え）による
見かけ上の変更。これを自動分類して、実質的な機能変更のみを抽出する。

**分類ルール（初期案）**
| 分類 | 判定基準 |
|---|---|
| 実質変更 | 新規追加・削除、Value/Expressionの内容変更 |
| 番号シフト | Meshoが「旧値→新値で同一内容」かつCallBoxの番号のみ変化 |
| 内部変数追加 | VarNameがSF/SFK/D1R〜D6R/ASVar等の省庁区分・代価表連携変数 |

**メリット**  
人間が確認すべき「実質変更」に絞り込むことで、照合コストが下がる。

---

### 案C：検出対象フィールドの拡張（丸め設定・規格名計上設定）

**概要**  
現在の差分レポートは KeisanItem の Value/Expression と SitsumonItem の Mesho/SitsumonVersion
しか検出していない。修正方針に現れる「丸め」「規格名計上」などの設定を検出できるよう拡張する。

**調査が必要なJSONフィールド**

| 修正方針の記述 | 対応するJSONフィールド | 調査ステータス |
|---|---|---|
| 丸め：一般労務(人) | KeisanItem の RoundingKind 等 | 未調査 |
| 規格名計上を設定 | Sitsumon017.IsKikakuKeijo | **実装済み（2026-05-26）** |

**実装済み（規格名計上）**  
`Sitsumon017` テーブルを差分対象に追加。カテゴリ「質問設定」として差分レポートに出力。  
検出フィールド: `IsKikakuKeijo`（規格名計上）/ `VarName`（変数名）/ `KeisanItemCD`（接続計算変数）/ `TaniMesho`（単位）/ `DefaultValue`

03工種での実績: 質問設定 変更6件（KeisanItemCD番号シフト）+ 追加1件（UT・規格名計上:あり）

**残課題（丸め設定）**  
複数工種のJSONを比較し、「丸め」に対応するフィールドを特定してから実装する。

---

### 案D：修正方針の自動生成（逆方向の活用）

**概要**  
差分レポートから「修正方針ドラフト」を逆生成する。
実装後のJSONから差分を出して修正方針と照合するのではなく、
差分レポートを人間が読める修正方針形式に変換して、設計書の自動作成に使う。

**想定用途**  
- 実装後のJSONから仕様書を起こす（リバースエンジニアリング）
- 差分レポートのレビュー補助（人間に読みやすい形式に変換）

---

## 優先度メモ（現時点の考え）

| 案 | 優先度 | 理由 |
|---|---|---|
| 案A（修正方針との照合） | 高 | 修正の抜け漏れ検証に直結する実用機能 |
| 案B（見かけ変更の分類） | 中 | 差分レポートの可読性向上。②テスト提案にも活きる |
| 案C（検出対象拡張） | 中 | JSONフィールドの調査が先。工種を重ねてから実装 |
| 案D（修正方針の逆生成） | 低 | 便利だが②③が完成してから検討でよい |
