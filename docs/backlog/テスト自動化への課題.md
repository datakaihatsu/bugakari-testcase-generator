## 自動テスト導入時のスコープ拡大方針

人手テストでは省略した他省庁の回帰テストを、自動テスト導入時にカバーする。

### 対象テストケース

| グループ | TC番号 | 件数 | 優先度 |
|---|---|---|---|
| 治山林道 × BH施工 | TC-013〜018 | 6 | 最高（今回も実行） |
| 道林務 × クレーン | TC-049〜054 | 6 | 高 |
| 他7省庁 × BH施工 | TC-001〜012, 019〜048 | 42 | 自動化後に実行 |

### 自動テストの処理順と出力設計

テストを2フェーズに分けて実行し、結果も別々に出力する。

**フェーズ1：必須テスト（リリースブロッカー）**
- SF=治山林道 × BH施工 の全パターン（差分テスト）
- 道林務 × クレーン施工 の最小確認（回帰テスト TC-050）
- このフェーズが全件PASSであればリリース可能

**フェーズ2：広域回帰テスト（リリース非ブロッカー）**
- 他7省庁 × BH施工 の全パターン
- 道林務 × クレーン施工 の残ケース
- このフェーズはリリース判断に影響しないが、問題があれば次回リリースで対処

**出力イメージ**

```
=== フェーズ1: 必須テスト結果 ===
TC-013  治山林道×BH×日当り×材料費+施工費  PASS
TC-014  治山林道×BH×日当り×施工費のみ     PASS
...（6件）
TC-050  道林務×クレーン×日当り×施工費のみ  PASS
結果: 7/7 PASS → リリース可

=== フェーズ2: 広域回帰テスト結果 ===
TC-001  国交省土木×BH×日当り×材料費+施工費  PASS
...（残り47件）
結果: 47/47 PASS
```

## 課題リスト

### 1. 省庁別テスト実行ポリシーの明文化

- 各省庁向けのデータリリース前に、その省庁のテストケースを実行することをルール化する
- テストケースCSV（テストケース仕様書_32-4527_裏込砕石工_2026.csv）を省庁リリース時の承認ゲートとして使用する

### 2. 自動テスト化の前提条件（未解決）

- 積算シミュレートソフトに対して外部からSFを設定して実行する手段が必要
- 代価表の計算結果を外部から取得・比較する仕組みが必要
- 現状は手動操作＋目視確認のみ

### 3. 期待値の外部単価依存部分

- S1〜S5（数量）は自動計算可能 → テストケースCSVに収録済み
- バックホウ運転費・最終金額は外部単価依存 → 自動テストの対象外（要別途検討）

### 4. 排ガス機械（第3次基準値）の未カバー

- 現在のCSVはデフォルト（2014年規制）のみ
- 第3次基準値を選択した場合のFG~01=64の動作確認が未実施
- S1〜S5には影響しないが、バックホウ運転費の参照先が変わることの確認が必要
