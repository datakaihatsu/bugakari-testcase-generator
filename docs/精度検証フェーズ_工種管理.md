## テストケース作成の制限事項

> ※ 最終マニュアル / README の素材メモ。

- **供用日の運転費（#19 バックホウ型の損料・賃料系工種）はテストケース作成不可能**と位置づける（2026-06-10 ユーザ決定）。イレギュラーな構造が多く開発コストに見合わない。
- **B-22 外部変数シナリオの「薄いシナリオ」**（2026-06-18）: B-22 は「外部/計設定変数の非既定分岐」を自動でシナリオ化するが、**計設定/環境変数（msk・O~atk・O~pre 等）と、たまたま未定義の計算/寸法変数（SF・wb 等）を JSON 構造だけで完全には区別できない**。このため、計算/寸法変数が拾われると価値の薄い追加ファイルが出ることがある。
  - **具体例: #30 型枠工(覆工)**。`SF`（スライドセントル断面寸法系の計算表変数・既定6.0）が拾われ、`step3.0_テストケース_SF=6.1.csv`（本体TCとほぼ同一）と `step3.0_テストケース_SF=6.4.csv`（質問列なし＝期待値だけの裸のTC）が生成される。これらは検証価値が低い。
  - **運用方針**: ファイル名に必ず「変数=値（＋選択肢テキスト）」を入れているので、**人がファイル名で要否を判断し、薄いシナリオは運用でテスト対象から外す**（例: `_msk=4_配合比選択区分(大阪市)` は検証する／`_SF=6.4` は見送る）。エンジンで完全自動の取捨選択はしない（やむを得ない制限事項）。
