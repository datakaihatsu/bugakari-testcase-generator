## ビジョン

> **旧JSON + 新JSON を投入するだけで、テストケースCSVが自動生成される**

プロジェクトごとに改修される10〜30工種を対象に、
差分抽出 → テスト提案 → CSV生成 の3ステップを自動化する。

---

## アーキテクチャ（①②③パイプライン）

```
旧JSON + 新JSON
    ↓
① 差分抽出（完全自動・決定論的）
    → step1_差分レポート.csv
       カテゴリ: 代価表 / 計算表 / 質問 / 質問設定 / 選択肢 / フロー
       変更種別: 変更 / 追加 / 削除

    ↓ 人間確認（10〜30工種なら現実的なコスト）

② テスト提案リスト生成（ルールベース自動）       ← 実装済み・精度調整中
    → step2_提案リスト.csv
       到達不可能パスの除外（SF固定値 → 省庁列除外など）
       テスト軸の候補提示

    ↓ 人間確認・承認

③ テストケースCSV生成（完全自動）                ← 実装済み・精度調整中
    → step3_テストケース.csv
```

実行コマンド（①②③連続実行）:
```
python 共通/pipeline.py <old_json> <new_json> <output_dir>
```

## 進化の経緯

```
Phase 1（旧）: 工種ごとに手書きバッチ
  JSON → 人間が分析 → 手書きCSV行 → generate_all_testcases.py
  問題: 同じ工種を再実行しても同じ出力が保証されない

Phase 2（現在）: ①②③パイプライン
  JSON → ① 差分抽出（自動） → ② テスト提案（ルールベース） → ③ CSV生成（自動）
  ①②③すべて実装済み。②③は精度調整中。
  利点: 同じJSONなら常に同じ①出力（決定論的）

Phase 3（将来）: ②のルール集が成熟した全自動化
  工種を重ねるごとに②のrules.mdが育ち、人間確認の必要が減る
```
