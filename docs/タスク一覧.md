### J3 の機能的根拠 (Sirius ソース調査結果)

`SitsumonFlags` の値:
- `105` = `IsGaia9SitsumonItem` (Sirius テストでコメント確定)
- `108` = Gaia9 関連 (常に 105 とセット)
- `1, 2, 3, 100` 等 = **SekisanEnv 連動フラグ**。`Sitsumon019AutoSelectBySekisanEnvTest.cs` 参照。積算環境設定で「あり/なし/適時聞く」 が決まる。JSON に SekisanEnv 値が含まれないため、テストケース生成時には未確定 → 安全側で **fix**。
- `SitsumonKind=17` (数値入力) は全て `MinKigou≥1` で UI 可視 = ユーザ入力対象 → fix。

```bash
python3 -c "import ast; ast.parse(open('共通/step2_proposals/generate_proposals.py', encoding='utf-8').read())"
```
