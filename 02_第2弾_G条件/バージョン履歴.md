# G条件・テストケース生成ツール バージョン履歴

配布物の版を受け渡し先と突き合わせるための履歴。
**バージョンの正は `webapp/version.py`**（画面ヘッダー右上に `v○.○.○ (YYYY-MM-DD)` で表示）。

採番: セマンティック ＋ ビルド日
- MAJOR … 使い方が変わる非互換変更
- MINOR … 機能追加（タブ追加・新モード等）
- PATCH … 不具合修正・生成ロジックの補正

リリース手順:
1. `webapp/version.py` の `APP_VERSION` / `BUILD_DATE` を更新
2. 本ファイルへ1行追記
3. 配布zipを差分リビルド（既存zipを展開→`app/` だけ最新masterで上書き→再zip）
4. 共有ドライブ `…/Tool/5.外部設計/G条件とテストケース作成/Gaia歩掛テストケースツール.zip` を差し替え
