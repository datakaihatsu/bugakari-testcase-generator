# 第2弾_G条件（新ロジック・開発中）

第2弾＝**G条件を生成する新ロジック**のトラック。`01_第1弾_運用化/` 完成後に本格開発する想定で、現状はエンジン基盤を第1弾から複製した素地。

## 第2弾の考え方
- 既存（商品）歩掛JSONから **G条件を逆生成**する。G条件はJSONから正確に起こせる（構造化データ起点＝表記揺れなし）。
- G条件の出力フォーマット＝**「施工単価入力基準表」の様式**（赤本J条件に整合）:
  - 施工歩掛コード・施工単位 ＋ 入力条件 J1..Jn（条件名と区分①②…）
  - (注)＝**入力条件に影響する分岐ルールのみ**（例: J1=②ならJ3不要）。単価登録・数量算出は対象外（入力条件に効かない／単価はJSON外）。
  - J列＝エンジンの既存vary軸判定を流用。サンプル: `docs/02_第2弾_G条件サンプル.png`（06土のう積工 WB252620）。
- 人が改定後G条件を編集 → G条件からTC生成 → 改定後JSONと突き合わせ（乖離1.5拡張）。

- 共有資産（`工種別/`・`進捗報告/`・`docs/`）はプロジェクト直下を参照。
