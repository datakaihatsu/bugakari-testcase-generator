# 第1弾_運用化（現在の作業拠点・仮運用）

第1弾＝**現ロジックの活用で最初に運用化**するトラック。現在の開発・回帰はここで行う。

## 第1弾の考え方
- 入力を「修正後JSONから」→「**商品JSON（改定前の既存版）＋改定内容から**」に変える（テストファーストを壊さない）。
- エンジンは TC の叩き台を出し、人が改定内容を盛り込んで改定後TCを作る。
- 乖離チェックは**人作成TCを主軸**に改定後JSONで合否＋未カバー差分。修正方針があれば補助併用、無ければTC単独。
- 人作成TCの形式は現行 `step3.0_テストケース.csv` と同一。
